# 길담 (Gildam)

걷기·달리기·자전거·등산 활동을 GPS로 기록하거나 GPX/TCX로 가져와, 지도와 통계로 **다시 보는** 웹앱입니다.
서버 없이 브라우저만으로 동작하며, 모든 데이터는 기기 안(IndexedDB)에만 저장됩니다.

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1단계 | 실시간 기록, 활동 상세, GPX/TCX 가져오기·GPX 내보내기, 설정·백업 | ✅ 완료 |
| 2단계 | 3D 리플레이, 사진 결합 | ✅ 완료 |
| 3단계 | 통계, 공유 카드, 영상 내보내기, PWA | ⏳ 예정 |

## 실행

빌드 과정이 없습니다. 정적 파일 서버만 있으면 됩니다.

```bash
python3 scripts/serve.py 5173   # 캐시 비활성화 개발 서버
# 브라우저에서 http://localhost:5173
```

> 위치 기록(Geolocation)과 Wake Lock 은 **HTTPS 또는 localhost** 에서만 동작합니다.
> 휴대폰에서 시험하려면 GitHub Pages 에 배포하거나 HTTPS 터널을 사용하세요.

### GitHub Pages 배포

저장소 Settings → Pages → Branch 를 `main` / `(root)` 로 지정하면 됩니다. 모든 경로가 상대 경로라 하위 경로(`/<repo>/`)에서도 동작합니다.

## 1단계 기능

- **기록 탭**: 활동 종류 선택 → 시작 / 일시정지 / 계속 / 종료
  - `watchPosition` 고정밀 모드, 정확도 30m 초과 지점 제외
  - 활동 종류별 최대 속도(걷기·등산 4, 달리기 9, 자전거 30 m/s)를 넘는 GPS 튐 지점 제외
  - Screen Wake Lock 으로 화면 꺼짐 방지, 탭 복귀 시 자동 재요청, 미지원 브라우저는 안내 문구 표시
  - 기록 중 데이터는 10초마다 임시 저장 → 탭이 닫혀도 다음 실행 때 "이어서 기록" 가능
  - 탭을 이동해도 기록은 계속됨
- **상세 화면**: 속도 5분위 색상 경로 + 범례, 시작/종료 마커, 거리·이동/경과 시간·평균 페이스(자전거는 평균 속도)·최고 속도·누적 상승·최고 고도·칼로리(추정치 표기), 고도 프로필 차트, 1km 구간 페이스 표, 이름·종류 수정, GPX 내보내기, 삭제
- **보관함**: 최신순 목록, 종류 필터, 여러 파일 동시 가져오기, 샘플 불러오기
- **설정**: MapTiler 키, 체중, 기본 종류, 테마(시스템/밝게/어둡게), 집 주변 숨기기 위치·반경(3단계 공유 기능에서 적용), 전체 JSON 백업/복원(복원 시 데이터 검증)

## 2단계 기능

- **3D 리플레이** (상세 화면 → `▶ 3D 리플레이`)
  - 카메라가 경로를 따라 기울어진 시점(pitch 62°)으로 이동하며 진행 방향을 부드럽게 따라 회전
  - 재생/일시정지(스페이스바), 재생 위치 슬라이더, 속도 0.5×·1×·2×·4× (1× 기준 1km당 6초, 30~120초)
  - 지나온 구간을 활동 색으로 채우고, 거리·경과 시간·고도를 실시간 오버레이
  - 사진 지점에 도달하면 3초간 멈추고 사진 팝업 → 누르면 크게 보기
  - MapTiler 키가 있으면 3D 지형(terrain-rgb, 1.4배 과장) 표시, 없으면 평면 지도에서 기울인 시점으로 재생
  - 지도를 직접 끌면 재생이 멈춤
- **사진 결합** (상세 화면 → `📷 사진 추가`, 여러 장 가능)
  - EXIF GPS 가 있으면 가장 가까운 경로 지점에 배치 (경로에서 1km 이내)
  - GPS 가 없거나 너무 멀면 촬영 시각(`DateTimeOriginal` + `OffsetTimeOriginal`)으로 배치 (활동 시간 ±10분 이내)
  - 둘 다 안 되면 이유와 함께 거부
  - 1600px JPEG + 썸네일로 줄여 IndexedDB 에 저장. canvas 재인코딩으로 **원본 EXIF(위치 포함)는 저장본에서 제거**
  - 상세 지도에 사진 마커, 사진 목록(위치·시각·배치 방식), 크게 보기, 삭제
  - 활동을 삭제하면 사진도 함께 삭제, 전체 백업/복원에 사진 포함

### 계산 방식

| 항목 | 방식 |
|---|---|
| 거리 | Haversine 합. 일시정지(세그먼트) 사이 거리는 제외 |
| 이동 시간 | 0.3 m/s 미만 구간 제외 |
| 최고 속도 | 최소 10초 구간 평균 속도의 최댓값 (순간 튐 완화) |
| 누적 상승 | 고도 5점 이동평균 후 3m 히스테리시스 |
| 칼로리 | MET × 체중 × 이동 시간 (걷기 3.5 / 달리기 9.8 / 자전거 7.5 / 등산 6.0) — **추정치** |
| 구간 페이스 | 1km 경계 시각을 선형 보간, 일시정지 시간 제외 |
| 리플레이 위치 | 진행률을 **거리 기준**으로 보간 (정지 구간에서 멈춰 있지 않음). 시간 오버레이는 해당 위치의 실제 기록 시각 |
| 리플레이 방향 | 현재 위치에서 전체 거리의 3%(80~400m) 앞 지점을 향한 방위각을 0.7초 시정수로 보간 |

## 지도

- 설정에 **MapTiler 키**를 넣으면 MapTiler Outdoor 지도를 사용합니다 (2단계 3D 지형에 필요).
- 키가 없으면 OpenStreetMap 기본 타일로 표시됩니다. OSM 타일은 [이용 정책](https://operations.osmfoundation.org/policies/tiles/)상 대량 사용에 적합하지 않으니, 배포 시에는 MapTiler 키 사용을 권장합니다.
- 키는 해당 기기의 localStorage 에만 저장됩니다. 단, 지도 타일 요청 URL 에 포함되어 MapTiler 로 전송되므로 MapTiler 대시보드에서 **허용 도메인(Allowed HTTP origins)** 을 지정해 두세요.

## 샘플 데이터

`sample/` 의 GPX 는 `scripts/make-samples.mjs` 로 생성한 **합성 데이터**입니다 (실제 등산로·주로와 정확히 일치하지 않음).

| 파일 | 내용 | 확인 포인트 |
|---|---|---|
| `hiking-bukhansan.gpx` | 북한산 우이동 → 백운대(836m) 왕복 6.5km, 정상 15분 휴식 | 누적 상승 ~715m, 휴식 구간이 이동 시간에서 제외되는지 |
| `running-hangang.gpx` | 여의도 한강 5.3km 왕복, 반환점 30초 정지 | GPS 튐 1개가 가져오기 시 제외되는지 |

```bash
node scripts/make-samples.mjs   # 다시 생성
```

`sample/photos/` 는 등산 샘플 경로에 맞춘 테스트 사진입니다 (`python3 scripts/make-sample-photos.py`, Pillow 필요).

| 파일 | EXIF | 기대 결과 |
|---|---|---|
| `photo-1-ascent.jpg` | GPS + 촬영 시각 | 오르막 약 1km 지점에 GPS 로 배치 |
| `photo-2-summit.jpg` | GPS + 촬영 시각 | 정상에 GPS 로 배치 |
| `photo-3-descent.jpg` | 촬영 시각만 (+09:00) | 하산 중 지점에 시각으로 배치 |

등산 샘플을 불러온 뒤 상세 화면에서 세 장을 함께 올리고 리플레이를 재생해 보세요.

## 테스트

```bash
npm test   # node:test + 커버리지 (Node 22+)
```

- 단위 테스트: 거리·필터·통계·구간·포맷·GPX 직렬화·활동 생성/검증·SVG 대체 지도·사진 매칭·EXIF 시각·리플레이 보간 (49개)
- GPX/TCX **파싱**은 브라우저의 `DOMParser` 가 필요해 Node 에서 실행하지 않습니다. 1단계에서는 브라우저에서 TCX, 경로(rte)만 있는 GPX, 잘못된 XML, 범위 밖 좌표, GPX 내보내기→가져오기 왕복을 직접 확인했습니다.

## 알려진 한계

- **iOS 백그라운드 GPS**: iOS Safari(및 iOS의 모든 브라우저)는 화면이 꺼지거나 다른 앱으로 전환하면 웹페이지의 위치 업데이트를 중단합니다. 기록 중에는 화면을 켜 두어야 하며, Wake Lock 은 iOS 16.4+ 에서만 지원됩니다. 끊긴 동안의 경로는 직선으로 이어집니다.
- **Android 백그라운드**: 화면이 꺼지면 Chrome 도 위치 업데이트 빈도를 크게 줄일 수 있습니다. 배터리 최적화 예외 설정이 도움이 될 수 있습니다.
- **WebGL 필요(지도)**: MapLibre 는 WebGL 로 지도를 그립니다. 브라우저의 하드웨어 가속이 꺼져 있거나 GPU 가 차단된 환경에서는 배경 지도 대신 **SVG 경로 모양**(속도 색상·시작/종료 표시)만 보여 주고 안내 문구를 띄웁니다. 기록·통계·GPX 입출력은 정상 동작합니다. 2단계 3D 리플레이는 WebGL 이 꼭 필요합니다.
- **사진 촬영 시각의 시간대**: 많은 카메라가 EXIF 에 시간대(`OffsetTimeOriginal`)를 넣지 않습니다. 이때는 **현재 기기의 시간대**로 해석하므로, 해외에서 찍은 사진을 한국에서 올리면 시각 매칭이 어긋날 수 있습니다 (GPS 가 있으면 영향 없음). 카메라 시계가 틀려도 마찬가지입니다.
- **HEIC 사진**: iPhone 기본 형식인 HEIC 는 Safari 외 브라우저에서 열 수 없습니다. iPhone 설정 → 카메라 → 포맷 → "높은 호환성"을 쓰거나 JPEG 로 변환해 올려 주세요.
- **사진 저장 용량**: 사진은 1600px 로 줄여 저장(장당 약 0.2~0.5MB)하지만 많이 쌓이면 브라우저 저장 한도에 닿을 수 있습니다.
- **리플레이와 OSM 타일**: 키 없이 리플레이하면 카메라 이동 중 OSM 타일을 많이 요청합니다. 배포·실사용 시에는 MapTiler 키를 넣어 주세요.
- **Wake Lock**: 배터리 절약 모드에서는 요청이 거부될 수 있으며, 탭 전환 시 자동 해제되어 복귀 때 재요청합니다.
- **고도**: 휴대폰 GPS 고도는 오차가 커서(±10~30m) 누적 상승이 실제와 다를 수 있습니다. 기압계 고도는 웹에서 접근할 수 없습니다.
- **MediaRecorder(3단계 영상 저장)**: Chrome/Edge/Firefox 는 WebM 을 지원하지만 Safari 는 MP4 만 지원하는 등 브라우저별 차이가 있습니다. 3단계 구현 시 상세히 기록합니다.
- **저장 공간**: 브라우저 데이터를 지우거나 사파리가 장기간 미사용 사이트 데이터를 정리하면 기록이 사라질 수 있습니다. 설정 → 전체 백업을 주기적으로 해 두세요.
